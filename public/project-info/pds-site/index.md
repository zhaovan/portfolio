The Persona Design System (PDS) Site was launched in Q1 of 2026. Created and designed as an all in one hub for documentation, it is used internally across the company to keep engineers, designers, and others up to date on the standards of what are currently being used within the design system.

This project runs an internal CMS that fetches directly from storybook, figma, and github documentation to provide the most up to date documentation. The site is deploy on cloudflare, and provides IP-based gating to prevent internal documentation from being consumed by external users.
