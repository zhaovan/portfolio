Kernel Magazine is a literary magazine under Reboot focused on tech, society, and power. A yearly print and digital magazine, it's one of Reboot's biggest projects along with the student fellowship. The first issue started in 2022, and it's printed every year since then.

I had the opportunity to work as a layout and web designer, and web developer for the project along with four other talented people (one print designer, one web designer, and two developers). Our goal for this project was to develop a flexible logo and branding system that could work across both Kernel's web and print presence, and surface it's various needs to the types of content that we had inside the magazine (essays, interviews, fiction, poetry).
